# Image Assets Note

All local static images and neutral SVG placeholders for the MVP live in `frontend/public/images/` and are registered in `frontend/src/config/images.js`.

See [IMAGE_ASSETS.md](../../../../IMAGE_ASSETS.md) at the repository root for the complete asset manifest, final filenames, dimensions, and alt-text rules.

Do not add photos of real Members, case documents, or real personal data. Do not use Firebase Storage or external stock-image URLs for MVP assets.
